# バックエンド引き渡しメモ

## このHTMLモックの役割

バックエンド担当が、画面構造・検索条件・表示項目・画面遷移を把握するための静的HTML。

実装時は表示パーツをテンプレート化し、認証、応募者取得、検索、ページネーション、詳細表示、ファイル取得をバックエンド側で接続する想定。

## 対象画面

- `index.html`：管理画面ログイン
- `applicants.html`：応募者一覧
- `applicant-detail.html`：応募者詳細

PHP化後のファイル名やルーティング方式は、バックエンド側の構成に合わせて変更してよい。

## バックエンドで必要になる想定処理

- 管理画面の認証・ログアウト
- 応募者総数、期間内応募者数の取得
- 応募者一覧の取得
- 検索・絞り込み
- 応募日時の降順ソート
- ページネーション
- 応募者詳細の取得
- 職務経歴書の閲覧またはダウンロード
- 未認証時、該当データなし、ファイルなしの制御

## ログイン

- フォームは `method="post"` を使用する
- メールアドレスは `name="email"`、パスワードは `name="password"` とする
- ログイン状態保持は `name="remember"` とする
- CSRFトークン用のhidden inputはバックエンド実装時に追加する
- 認証失敗時は `.login__error` を表示し、`role="alert"` を維持する
- ログイン成功後は応募者一覧へ遷移する
- パスワードや認証エラーの詳細をログへ平文保存しない

## 応募者一覧

### 検索フォーム

静的HTMLモックでは、次のGETパラメータを想定している。

| 項目 | `name` | 内容 |
| --- | --- | --- |
| キーワード | `keyword` | 氏名またはメールアドレス |
| 応募日・開始 | `date_from` | `YYYY-MM-DD` |
| 応募日・終了 | `date_to` | `YYYY-MM-DD` |
| 就業状況 | `status` | 現在の就業状況 |
| 経験年数 | `experience` | 保険業界での経験年数 |

値の候補は、応募フォーム側で保存する値と揃える。画面表示用文言とDB保存値が異なる場合は、バックエンド側で変換する。

### 一覧データ

初期表示は応募日時の新しい順とする。

各行には、バックエンド側で応募者を特定できるIDが必要。詳細URLはルーティングに合わせ、クエリ形式またはパス形式で生成する。

```text
applicant-detail.php?id=123
/admin/applicants/123
```

上記は形式例であり、現時点ではURL仕様を固定しない。

### ページネーション

- 1ページあたりの表示件数は未確定
- 検索条件を維持したままページ移動できるようにする
- 現在ページには `aria-current="page"` を付与する
- 0件時は空状態を表示し、テーブルに仮データを残さない

## 応募者詳細

- URLやルートから取得した応募者IDを使って1件取得する
- 表示項目と順序は `SPEC.md` を正とする
- 未入力項目の表示ルールは、空欄または `未入力` のどちらかに実装前に統一する
- 応募日時は入力内容と分けて画面上部に表示する
- 一覧へ戻るリンクでは、可能なら検索条件とページ番号を保持する

## 職務経歴書

- 公開URLをHTMLへ直接埋め込まず、認証・権限確認後に取得できる構成を推奨する
- ファイル名を表示する場合は、HTMLエスケープを行う
- ファイルなしの場合はリンクを出さず、状態文言を表示する
- 許可するファイル種別、サイズ、保存期間は応募フォーム側の実装仕様と合わせる

## 表示とセキュリティ

- 氏名、住所、電話番号、メールアドレス、職務経歴書は個人情報として扱う
- 画面出力時はHTMLエスケープを行う
- 検索条件とIDの入力値を検証する
- 未認証ユーザーから管理画面へアクセスできないようにする
- 存在しない、または閲覧権限のない応募者は適切なエラーへ遷移させる
- 実データをHTMLモックやリポジトリへ含めない

## JavaScriptの扱い

JavaScriptは、静的HTMLモック上で操作感を確認するための最小限に留める。

行クリックを実装する場合でも、詳細画面へ移動できる通常の `a` を残す。検索、ページネーション、データ取得はバックエンド側で処理する。

## 実装前に確定が必要な項目

- 認証方式と利用者権限
- 一覧URL、詳細URL、応募者IDの受け渡し方法
- 1ページあたりの表示件数
- 検索項目の保存値
- 未入力項目の表示文言
- 職務経歴書の保存先と取得方法
- 選考ステータス、社内メモ、CSV、編集・削除を対象に含めるか
