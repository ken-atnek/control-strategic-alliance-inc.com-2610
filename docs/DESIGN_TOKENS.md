# デザイントークン・UIルール

## コンセプト

知的な信頼感、静かな成長感。

保険・金融領域に必要な誠実さと清潔感を土台に、余白、整列、抑えた装飾で現代的な印象を作る。

## カラー

| 用途 | 変数名 | 値 |
| --- | --- | --- |
| Primary | `primary` | `#1C2B45` |
| Accent | `secondary` | `#B08D57` |
| Background | `background` | `#FAF9F6` |
| Surface | `surface` | `#FFFFFF` |
| Main text | `text-primary` | `#1F2328` |
| Secondary text | `text-secondary` | `#5C6470` |
| Border / Divider | `border` | `#E4E1DA` |

ゴールドはCTAやアイコンなどのアクセントに限定する。

管理画面では同じ値をSass変数またはCSSカスタムプロパティとして使用する。

## タイポグラフィ

- フォント：Noto Sans JP
- 見出し：Bold / Medium
- 本文：Regular
- 明朝体は使用しない
- 日本語と英数字が混在しても読みやすいウェイトを選ぶ

サイズと行間の固定値は未定義。既存の管理画面モックを基準にする。

## 余白

- 通常の要素間は24〜32pxを基準にする
- 情報量が多い画面でも、検索欄や表を詰め込みすぎない
- 表示密度と可読性のバランスを優先する

## UIルール

- Primary CTA：ネイビー背景＋白文字
- Accent CTA：ゴールド背景＋ネイビー文字
- Secondary button：アウトライン、またはテキストリンク＋矢印
- カード：白背景＋薄いボーダー。影は控えめにする
- フォーム：小さめの角丸＋薄いグレーの枠線
- 同じ役割の要素は、色、余白、角丸、文字スタイルを統一する
- 管理画面では装飾より、検索、比較、確認のしやすさを優先する

## レイアウト

- PC利用を前提とする
- 管理画面の基準幅とブレークポイントは実装確認時に確定する
- テーブルは必要に応じて横スクロールを許容する
- 詳細画面は応募フォームの4カテゴリと同じ順序で表示する

## ロゴ

ロゴはデザイン元の `assets/images/logo.png` を使用する。取り込み時は本プロジェクトの `assets/images/logo.png` へ配置する。
